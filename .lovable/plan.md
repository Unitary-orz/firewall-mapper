# 同链路折叠样式调整：展开变轻、收起变明显

## 收起状态（加重）
- 汇总条改为与路径行同宽的浅底胶囊条（淡灰底 + 细边框，左侧同色状态细条），不再是一行灰字。
- 内容：`▸ 另 N 个端口` 作为按钮文字（常规字重、前景色），其后端口简写列表（等宽、次要色），右侧「已关联 x / 未关联 y」小计。
- 悬停时底色略深，明确可点击。

## 展开状态（减轻）
- 展开的端口行不再用完整卡片：去掉边框、左侧粗色条和背景，改为紧凑子行（行高更低，间距更小）。
- 子行的来源、NAT、目的整体淡化（降低透明度，NAT 胶囊改透明底），只保留服务/端口和策略状态正常显示。
- 子行状态用左侧 2px 细色点/细线表示，保持五列与表头对齐。
- 汇总条移到子行下方显示为「▾ 收起」，样式同收起状态但更轻。

## 技术细节
- `src/components/access/FocusRows.tsx`：`FocusLineRow` 增加 `variant="sub"`（无卡片边框、淡化前三列、透明 NAT 胶囊）；`FoldedChain` 汇总按钮换成上述胶囊条样式。
- 浏览器用真实配置 WAF-IP 截图对比收起/展开及手机端。
