# 同一条 NAT 只占一行，端口在“服务 / 端口”里按关联状态聚合

## 规则
- 同一条链路（来源、NAT、目的都相同）始终只显示**一行**，不再按端口拆成多行。
- “服务 / 端口”列分两组显示：
  - **已关联**：直接列出端口标签（服务名 + 端口），最多显示 2 个，多的收成“+N”，悬浮查看全部及各自命中的策略。
  - **未关联**：收成一个浅琥珀小标签“N 未关联”（只有 1 个时直接显示端口），悬浮/手机点按查看列表。
- “策略状态”列按整行汇总：有任一端口关联 → “已关联 X”（X = 去重后的策略数）；全部未关联 → “未关联策略”；有部分未关联时可在数量旁轻提示。
- 行左侧颜色：有关联用蓝色，全部未关联用琥珀色，Deny 仍为红色。
- 只有 1 个端口时与现在一样。
- Service 视图（以端口为焦点）保持一端口一行，不聚合。
- “隐藏未关联策略”开启时：未关联的端口从标签里去掉，整条链路都未关联则整行隐藏；统计口径不变。

## 不同端口关联不同策略
- 仍是一行。已关联端口按“命中的策略集合”分组：命中相同策略的端口合成一个标签（如 `https 443 · http 80`），命中不同策略的各自一个标签。
- 每个标签右上角带小数字表示命中策略数；悬浮显示：端口列表 + 对应策略（编号、动作、来源/目的）。
- 有 Deny 的端口组单独成标签并用红色描边，不与 Permit 合并；行左侧颜色只要有 Deny 即为红色。
- “策略状态”列显示去重后的总策略数，悬浮按端口列出“端口 → 策略”对照。

## 样式示意
```text
来源        NAT/直连      目的      服务 / 端口                         策略状态
[政务中心]  [DNAT ...]   WAF-IP    https 443  [https 443 · http 80 ¹] [8443 ²] [16 未关联]   已关联 3
```
