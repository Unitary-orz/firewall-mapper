# 同链路多端口折叠：从“服务 / 端口”列起排

## 目标
折叠条和展开后的端口不再占满整行卡片，只从“服务 / 端口”列开始，挂在主行下方，像主行的“端口续行”。

## 样式
```text
来源        NAT/直连        目的      服务/端口          策略状态
[政务中心]  [DNAT ...]     WAF-IP     https 443         已关联 1     <- 主行（不变）
                                    ├ › 另 19 个端口  已关联 3 · 未关联 16   <- 收起
```
展开后：
```text
[政务中心]  [DNAT ...]     WAF-IP     https 443         已关联 1
                                    │      http 80      已关联 1
                                    │     tcp/8443      未关联
                                    └ ‹ 收起
```
- 前三列（来源 / NAT / 目的）留空，不再重复显示淡化的来源、NAT、目的。
- 左侧在“服务 / 端口”列起点画一条细竖线，把续行串到主行下方，表示同一条链路。
- 收起态：细描边小胶囊“› 另 N 个端口”+ 前几个端口号，右侧在策略状态列显示已关联 / 未关联计数；悬停加深。比现在更集中、更醒目，但不铺满整行。
- 展开态：每个端口一行紧凑行，只有服务标签和策略状态，与表头列对齐；无边框无底色，状态用策略列文字颜色表达。末尾一个很轻的“收起”。
- 手机端：保持现有纵向卡片；折叠条改为卡片下方的小胶囊，展开后为简洁的“服务 + 状态”列表。

## 技术细节
- 仅改 `src/components/access/FocusRows.tsx`：
  - `FoldedChain` 的 toggle 与子行改用 `FOCUS_GRID`，内容放在 `col-start-4 col-span-2`（收起胶囊）或第 4、5 列（子行），前三列为空。
  - 新增轻量 `FoldPortRow`（仅服务 + 策略状态）替代 `FocusLineRow sub`，移除 `sub` 分支。
  - 竖线用第 4 列容器的 `border-l` 实现。
- 用真实配置在 WAF-IP 截图验证收起 / 展开及 1041px、390px 无溢出。
